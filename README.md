# CYBER QUEST — Защити свой аккаунт

Интерактивная учебная игра для подростков 13–16 лет о паролях, двухфакторной аутентификации, мошеннических сообщениях и личных данных. Проект работает в браузере без сервера, аккаунтов, внешних API и сбора пользовательских сведений.

## Локальный запуск

Нужен Node.js 20 или новее.

```bash
npm install
npm run dev
```

Открой адрес, который Vite покажет в терминале. Для production-сборки выполни:

```bash
npm run build
npm run preview
```

Готовый статический сайт появится в папке `dist/`.

## Публикация на GitHub Pages

1. Создай репозиторий на GitHub и отправь в ветку `main` эти файлы вместе с `package-lock.json`.
2. В репозитории открой **Settings → Pages** и выбери **GitHub Actions** в качестве источника публикации.
3. При отправке изменений в `main` workflow `.github/workflows/deploy.yml` установит зависимости, соберёт сайт и опубликует `dist/`.
4. Ссылка появится в **Settings → Pages** после завершения первого запуска workflow.

В `vite.config.js` задан `base: './'`, поэтому ресурсы загружаются и на адресе проекта вида `username.github.io/repository-name/`.

## Игровая механика

- Пять последовательных уровней, 26 заданий и очко за каждый правильный ответ.
- Объяснение показывается после выбора, в том числе после ошибки. Ошибка не блокирует прохождение.
- В финале показывается процент и рейтинг: эксперт цифровой безопасности (90–100%), уверенный защитник (70–89%), начинающий кибердетектив (50–69%) или дополнительная тренировка (меньше 50%).
- Уровень можно повторить; при повторе его прежние ответы исключаются из результата и начисляются заново.
- Кнопка «Начать заново» возвращает к главному экрану. Прогресс живёт только в открытой вкладке и не записывается в `localStorage`.
- В сортировке личных данных используются кнопки категорий, поэтому перетаскивание не требуется и мобильные устройства поддерживаются.

## Где менять содержание

- `src/data/missions.js` — уровни, задания, варианты, правильные ответы, объяснения и пороги рейтинга.
- `src/game/gameEngine.js` — переходы между экранами, проверка ответов, очки и повтор уровня.
- `src/ui/render.js` и `src/ui/icons.js` — разметка экранов и встроенные SVG-иконки.
- `src/styles.css` — цвета, оформление, анимации и адаптивные размеры.
- `vite.config.js` — настройки сборки и базовый путь.
- `.github/workflows/deploy.yml` — автоматическая сборка и публикация.

Все пароли и переписки внутри игры — вымышленные примеры. Интерфейс не просит вводить настоящие пароли, коды подтверждения или контактные данные и ничего не отправляет наружу.
